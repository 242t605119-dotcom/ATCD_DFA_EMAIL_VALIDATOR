ABOUT THE PROJECT

DFA Student Login Authentication

Understanding how Deterministic Finite Automata can be used for student authentication and input validation.

01

Project Overview

This mini-project demonstrates a student login authentication system using the concepts of Automata Theory and Deterministic Finite Automata. The system validates the student's email and password by processing their input character by character through DFA states.

02

What is DFA?

A Deterministic Finite Automaton is a mathematical model used to recognize patterns. For every state and input symbol, a DFA has a definite transition to another state.

03

Authentication Process

The system reads the entered email and password. Every character is processed through a sequence of states. If the input reaches the accepting state, it is considered valid. Otherwise, it is rejected.

04

Project Objective

The main objective is to understand how theoretical concepts of finite automata can be implemented in a practical web-based authentication application.

05

Why DFA?

DFA provides a simple and deterministic way to represent validation rules. Each input character produces a predictable state transition, making the authentication process easy to visualize.

06

Expected Outcome

The project helps students understand states, transitions, accepting states, rejected inputs, and how automata concepts can be connected with real-world input validation.

PROGRAM LOGIC

Technologies & Program Logic

Technologies and automata concepts used to build the DFA Student Login Authentication system.

01

HTML

HTML is used to create the structure of the login page, navigation bar, input fields, buttons, authentication result, and project sections.

02

CSS

CSS is used to design the interface, cards, navigation bar, login form, DFA visualization, buttons, responsive layout, and overall appearance.

03

JavaScript

JavaScript handles user input, validation, navigation between sections, authentication results, and dynamic DFA state generation.

04

DFA Logic

DFA logic processes every character of the input and moves from one state to another according to predefined transitions.

05

Email Validation

The email DFA verifies that the entered email has a valid local part and ends with the required domain: @ashokacollege.in.

06

Password Validation

The password DFA compares every entered character with the predefined authentication pattern and accepts the input only when the complete pattern matches.

07

SVG Visualization

SVG is used to display DFA states and transitions visually. Each character creates a transition from one state to the next state.

08

Program Flow

Input → Read Character → Find Transition → Move to Next State → Continue Processing → Accept or Reject.

PROJECT MODULES

DFA Authentication Modules

Different modules implemented as part of the DFA Student Login Authentication mini-project.

01

Student Login Module

Provides the login interface where students enter their email and password before authentication.

02

Email DFA Module

Processes the email character by character and verifies the required @ashokacollege.in domain.

03

Password DFA Module

Processes the password using sequential states and checks whether the complete password pattern is correct.

04

DFA Diagram Module

Dynamically creates states and transitions so that the user can visually understand how each character is processed by the DFA.

05

Authentication Result

After both inputs are processed, the system displays whether the login credentials are valid or invalid.

06

Future Enhancements

The project can be extended with database authentication, multiple student accounts, registration, password recovery, and improved security mechanisms.
